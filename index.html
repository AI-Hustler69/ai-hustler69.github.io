YT Studio

YT Studio is a private, personal desktop tool used by the owner of this site to manage their own YouTube channels. It is not offered to the public.

  • Schedules and updates metadata (titles, descriptions, tags, thumbnails, captions) of the owner's own videos through the official YouTube Data API.
  • Reads YouTube Analytics for the owner's own channels to review performance.
  • Optionally adds release reminders to the owner's own Google Calendar.

The tool runs only on the owner's computer. See the privacy policy.
