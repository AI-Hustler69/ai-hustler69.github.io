Privacy Policy – YT Studio

Last updated: 13 November 2026

Who uses this app

YT Studio is a personal tool used only by its owner to manage the owner's own YouTube channels. It is not distributed to other users.

What data it accesses

  • YouTube Data API: the owner's channels, videos, playlists and their metadata, in order to schedule videos and update titles, descriptions, tags, thumbnails and captions.
  • YouTube Analytics API: aggregated performance data of the owner's own channels (views, watch time, retention, subscribers).
  • Google Calendar API (optional): creating and updating release reminders in the owner's own calendar.

How data is stored

All data and OAuth tokens are stored locally on the owner's computer. YT Studio has no server and does not send Google user data to any third party. Google user data is not sold, shared or used for advertising.

Limited use

YT Studio's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app also complies with the YouTube Terms of Service; see also the Google Privacy Policy.

Revoking access and deletion

Access can be revoked at any time at myaccount.google.com/permissions. Revoking access invalidates the stored tokens; locally stored data can be deleted by removing the app's folder.
